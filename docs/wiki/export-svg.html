Export SVG

This guide shows how to export a drawing as SVG, and how to get a styled Mermaid render. It assumes you have a canvas open.

Export from the UI

  1. Type :export svg and press Enter. The command palette (Ctrl-p) also lists the exports.
  2. Choose what to write: the whole canvas, a dragged area or the selection.
  3. Enter a file path, such as diagram.svg.

Type :export alone to list the formats. :export mmd writes Mermaid. :export clidraw writes the save format.

Set export_padding in the configuration to change the margin around the drawing, in cells.

Export from the command line

Run clidraw export demo --svg diagram.svg. Use --mermaid or --clidraw for the other formats. Use - as the path to print to standard output.

Render Mermaid as SVG

The built-in SVG export draws plain shapes. For a Mermaid render, export Mermaid and render it with pele. pele needs Node.

  1. Choose Export Mermaid in the command palette and enter a file path, such as diagram.mmd.
  2. Install pele in a folder of your choice: npm install pele
  3. Save this script as render.mjs in the same folder: 
    import { readFileSync, writeFileSync } from 'node:fs';
import { render } from 'pele';

const { svg } = render(readFileSync(process.argv[2], 'utf8'));
writeFileSync(process.argv[3], svg);
  4. Render the diagram: node render.mjs diagram.mmd diagram.svg

pele has no command-line tool. The script calls its render() function.

Share a link to a diagram

  1. Press Ctrl-p and choose Copy share link.
  2. Choose what to share: the whole canvas, a dragged area or the selection.

The link opens the viewer at https://clidraw.shrtcts.fr/view.html# and carries the Mermaid text after the #. The browser does not send that part to a server, so the diagram stays private.

The viewer lays out the diagram again with pele. The layout can differ from the canvas. Free lines and free text are dropped, the same as in Mermaid export.

The status line shows the full link. Terminals that ignore OSC 52 copy nothing, so copy the link from the status line. Some terminals and tmux cap the copy length, so a large diagram can be copied incomplete.
