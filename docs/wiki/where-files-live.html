Where files live

clidraw keeps everything in plain files on your disk. This page explains where each file lives and why.

Canvases

clidraw picks the first directory that applies:

  • $CLIDRAW_HOME
  • $XDG_CONFIG_HOME/clidraw
  • ~/.config/clidraw

Each canvas is one <name>.clidraw.json file. The output is stable, so the files diff cleanly in git.

Settings

The file config.toml sits in the canvas directory. The first run writes it with every key commented out. See the configuration reference for the keys.

View and last canvas

clidraw remembers the viewport and the last canvas in state.json. It lives in $XDG_STATE_HOME/clidraw, else in ~/.local/state/clidraw.

Undo history

Each canvas has a history file at history/<name>.json, next to state.json. Three rules apply:

  • It holds at most history_limit steps.
  • clidraw drops it when the canvas file changes outside clidraw, because the steps no longer match.
  • Redo does not persist.

Edits from scripts and agents

A command-line or MCP edit to the canvas that the UI has open does not appear at once. The UI reloads the file at its next save. It then shows an error status and drops its own unsaved edits and the undo history.

Close the canvas in the UI before an agent edits it.
