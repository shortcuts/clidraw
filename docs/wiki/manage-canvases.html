Manage canvases

This guide shows how to work with several drawings. Each drawing is a canvas with a name.

Open or create a canvas

Run clidraw notes. clidraw opens the canvas notes, or creates it. Run clidraw alone to open the last canvas.

A canvas name cannot start with -.

Switch canvases

  1. Press Ctrl-p.
  2. Choose Canvases.
  3. Pick a canvas from the list.

A canvas named like a command, such as list or config, opens from this switcher and not from the command line.

List, rename and delete

  • clidraw list prints the canvas names.
  • clidraw rename notes ideas renames a canvas. Its undo history follows.
  • clidraw delete ideas deletes a canvas and its undo history.

Reuse shapes in the library

  1. Select the shapes.
  2. Type :lib save parts. clidraw refuses to overwrite an existing name.
  3. In any canvas, type :lib insert parts.

Type :lib list to see the names. Type :lib delete parts to remove one.

Back up or move a canvas

Copy the .clidraw.json file of the canvas. To open a copy, put it in the canvas directory. Where files live explains where that directory is.
