Install

This guide shows every way to install clidraw. Pick one method and run its command.

Install methods

Shell

Works on Linux and macOS. Run this command in your shell:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/shortcuts/clidraw/releases/latest/download/clidraw-installer.sh | sh

PowerShell

Works on Windows. Run this command in PowerShell:

powershell -ExecutionPolicy Bypass -c "irm https://github.com/shortcuts/clidraw/releases/latest/download/clidraw-installer.ps1 | iex"

Homebrew

Works on macOS and Linux with Homebrew installed:

brew install shortcuts/tap/clidraw

mise

Works with mise installed. This command installs the latest release for every project:

mise use -g github:shortcuts/clidraw

Cargo

Works with a Rust toolchain installed. Run this command to build clidraw from crates.io:

cargo install clidraw

Terminal requirements

clidraw needs a terminal with these three features:

  • True color: the terminal shows 24-bit colors.
  • Mouse reporting: the terminal sends mouse clicks and drags using SGR mouse mode.
  • Alternate screen: the terminal switches to a separate screen when clidraw starts.

Run clidraw probe to test your terminal. Move the mouse, click and scroll. Press q to quit.

Check the install

Run this command. It prints the installed version:

clidraw --version
