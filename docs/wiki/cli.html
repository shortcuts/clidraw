Command line

clidraw runs these commands without the UI, for scripts and agents. Each command prints JSON on stdout. A failure prints Error: <msg> on stderr and exits 1.

Commands

list

Usage: clidraw list

Prints the names of all canvases as a JSON array.

new

Usage: clidraw new <name>

Creates an empty canvas. Prints {"created":name}.

show

Usage: clidraw show <name>

Prints the canvas as JSON.

edit

Usage: clidraw edit <name>

Reads a JSON array of ops from stdin and applies them in order. Applies all ops or none. Prints {"applied":N,"ids":[...]}, where ids lists the created elements.

import

Usage: clidraw import <name> <path|->

Adds a Mermaid diagram from a file, or from stdin with -. The importer reads flowchart, sequence and class diagram syntax. Creates the canvas if it does not exist. Prints {"shapes":N,"lines":N,"skipped":N}.

export

Usage: clidraw export <name> --svg|--mermaid|--clidraw <path|->

Writes the canvas in one format to a file, or to stdout with -.

rename

Usage: clidraw rename <from> <to>

Renames a canvas. Prints {"renamed":to}.

delete

Usage: clidraw delete <name>

Deletes a canvas. Prints {"deleted":name}.

Edit ops

edit reads a JSON array of ops from stdin. Each op is an object. Its op field names the op. For example:

[{"op":"add_shape","x":0,"y":0,"label":"Hi"}]

add_shape

Adds a shape. Its size fits the label unless w and h are set.

  • x (required): Column, in cells.
  • y (required): Row, in cells.
  • id (optional)
  • kind (optional): Rect, Diamond, Cylinder, Parallelogram, Hexagon or Frame. Default: Rect.
  • w (optional): Width, in cells. Default fits the label.
  • h (optional): Height, in cells. Default fits the label.
  • label (optional)
  • color (optional): red, orange, yellow, green, blue or violet.
  • fill (optional): red, orange, yellow, green, blue or violet.
  • meta (optional): Key to value map.

add_text

Adds a line of text.

  • x (required): Column, in cells.
  • y (required): Row, in cells.
  • text (required): One line.
  • id (optional)
  • color (optional): red, orange, yellow, green, blue or violet.
  • meta (optional): Key to value map.

connect

Adds a line from one endpoint to another.

  • from (required): A shape id, or a [x, y] cell for a free end.
  • to (required): A shape id, or a [x, y] cell for a free end.
  • id (optional)
  • kind (optional): Line, Arrow, ArrowStart or ArrowBoth. Default: Arrow.
  • label (optional): One line.
  • meta (optional): Key to value map.

set

Changes one element. Set at least one field besides id.

  • id (required)
  • label (optional)
  • color (optional): red, orange, yellow, green, blue, violet or none. Use none to clear the color.
  • fill (optional): red, orange, yellow, green, blue, violet or none. Use none to clear the fill.
  • stroke (optional): solid, dashed or dotted.
  • border (optional): single, rounded, double or heavy.
  • align (optional): left, center or right.
  • bold (optional): true or false.
  • link (optional): One line. An empty string clears the link.
  • kind (optional): Rect, Diamond, Cylinder, Parallelogram, Hexagon or Frame. Changes the kind of a shape.
  • head (optional): Line, Arrow, ArrowStart or ArrowBoth. Changes the kind of a line.
  • meta (optional): Key to value map. An empty value removes the key.

resize

Sets the size of a shape.

  • id (required)
  • w (required): Width, in cells.
  • h (required): Height, in cells.

move

Moves one element.

  • id (required)
  • dx (required): Columns to move. Negative moves left.
  • dy (required): Rows to move. Negative moves up.

delete

Deletes one element.

  • id (required)

group

Groups two or more elements.

  • ids (required): At least two ids.

ungroup

Removes the group that holds the elements.

  • ids (required)

order

Changes the stacking order of elements.

  • ids (required)
  • z (required): front, back, forward or backward.

layout

Arranges elements by the lines between them.

  • ids (optional): Without ids, arranges every element.
  • dir (optional): td or lr. td runs top-down, lr runs left-right. Default: td.

Other commands

config

Usage: clidraw config

Prints the default config.toml.

probe

Usage: clidraw probe

Prints the kitty keyboard support result, then every terminal event. Use it to test a terminal.

mcp

Usage: clidraw mcp

Serves the eight commands above as MCP tools over stdio, for agent clients. See the MCP tools page.
