MCP tools

clidraw mcp serves the commands on the command line page as MCP tools over stdio, for agent clients. It reads one JSON-RPC message per line.

Setup

Add this server to the MCP config of your client:

{
  "mcpServers": {
    "clidraw": {
      "command": "clidraw",
      "args": ["mcp"]
    }
  }
}

A running UI reloads the canvas within half a second of an agent edit and drops its own unsaved edits. See Where files live.

Server instructions

The server sends these instructions to the client on connect. clidraw setup writes the same text into the rules file of Claude Code and Codex. Cursor has no rules file.

clidraw canvases outlive the agent that draws them. Draw so a later agent with no context can read and extend them.

Before you draw
- Call `search` with the topic. Call `show` on each canvas that matches.
- A canvas for the topic exists: extend it with `edit`. Never create a second one.
- No canvas exists: call `new`.

Canvas name
- Use `<repo>-<topic>` in lowercase kebab-case, such as `clidraw-auth-flow`. `<repo>` is the repository directory name.
- Name the topic. Do not use a date or a task name.

Shapes and lines
- Give every shape an `id` that names the thing: a short kind prefix, then the name, such as `svc-auth` or `db-users`.
- Give every line the id `<from>-to-<to>`, such as `svc-auth-to-db-users`.
- Never leave an id random. A later agent edits an element by its id.
- Give every shape a short `label` that a person reads. Label a line when its meaning is not obvious.
- Join shapes with `connect` and their ids, so the line follows the shapes.
- After you add shapes, call `layout`. Use `dir` `td` by default and `lr` for a flow over time.

Code and facts
- Point a shape at its code with `set` and `link`: `path` or `path:line`, relative to the repository root. `add_shape` has no `link` field, so call `set` after it.
- Put other facts a reader needs in `meta`, such as the owner or the data format.

Tools

list

List canvas names as a JSON array.

No parameters.

new

Create an empty canvas.

  • name (required, string): Canvas name

show

Print a canvas as JSON.

  • name (required, string): Canvas name

edit

Edit an existing canvas. Applies all ops or none and returns {"applied":N,"ids":[...]}. Each item of ops is an object whose op field names the op. Ops: add_shape (x, y, optional id, kind, w, h, label, color, fill, meta): Adds a shape. Its size fits the label unless w and h are set. add_text (x, y, text, optional id, color, meta): Adds a line of text. connect (from, to, optional id, kind, label, stroke, meta): Adds a line from one endpoint to another. set (id, optional label, color, fill, stroke, border, align, bold, link, kind, head, label_at, side_labels, meta): Changes one element. Set at least one field besides id. resize (id, w, h): Sets the size of a shape. move (id, dx, dy): Moves one element. duplicate (ids, dx, dy): Copies elements and the lines between them, shifted by dx and dy. Returns the new ids. delete (id): Deletes one element. group (ids): Groups two or more elements. ungroup (ids): Removes the group that holds the elements. order (ids, z): Changes the stacking order of elements. layout (optional ids, dir): Arranges elements by the lines between them. align (ids, mode): Aligns or spreads elements. Lines do not move.

  • name (required, string): Canvas name
  • ops (required, array): Each item is an object whose op field names the op. See the edit ops.

import

Add a Mermaid diagram below the existing content. The importer reads flowchart, sequence, class and state diagram syntax. Creates the canvas if missing.

  • name (required, string): Canvas name
  • mermaid (required, string): Mermaid diagram text

export

Render a saved canvas and return the text. With ids, render only those elements and the lines bound to them.

  • name (required, string): Canvas name
  • format (required, string): One of svg, mermaid or clidraw.
  • ids (optional, array): Element ids to export. Omit to export the whole canvas.

rename

Rename a canvas.

  • name (required, string): Canvas name
  • to (required, string): New canvas name

undo

Revert the last edit or import on a canvas. Returns {"undone":label}.

  • name (required, string): Canvas name

redo

Re-apply the last undone step. Returns {"redone":label}.

  • name (required, string): Canvas name

delete

Delete a canvas and its undo history.

  • name (required, string): Canvas name

templates

List the built-in template names as a JSON array.

No parameters.

template

Add a built-in template inside a frame, below the existing content. Creates the canvas if missing.

  • name (required, string): Canvas name
  • template (required, string): Template name from the templates tool

search

Search every canvas for a topic before drawing, to find existing work. Returns a JSON array of {canvas,id,kind,label,field}, best first.

  • query (required, string): Topic to search for

Errors

A failed tool call returns a normal result with isError set to true. Its text is Error: <msg>.

A call to a tool name that does not exist returns a JSON-RPC error with code -32602.
