MCP tools

clidraw mcp serves the commands on the command line page as MCP tools over stdio, for agent clients. It reads one JSON-RPC message per line.

Setup

Add this server to the MCP config of your client:

{
  "mcpServers": {
    "clidraw": {
      "command": "clidraw",
      "args": ["mcp"]
    }
  }
}

A running UI drops its unsaved edits when an agent edits the canvas it has open. Close the canvas in the UI first. See Where files live.

Tools

list

List canvas names as a JSON array.

No parameters.

new

Create an empty canvas.

  • name (required, string): Canvas name

show

Print a canvas as JSON.

  • name (required, string): Canvas name

edit

Edit an existing canvas. Applies all ops or none and returns {"applied":N,"ids":[...]}. Each item of ops is an object whose op field names the op. Ops: add_shape (x, y, optional id, kind, w, h, label, color, fill, meta): Adds a shape. Its size fits the label unless w and h are set. add_text (x, y, text, optional id, color, meta): Adds a line of text. connect (from, to, optional id, kind, label, meta): Adds a line from one endpoint to another. set (id, optional label, color, fill, stroke, border, align, bold, link, kind, head, meta): Changes one element. Set at least one field besides id. resize (id, w, h): Sets the size of a shape. move (id, dx, dy): Moves one element. delete (id): Deletes one element. group (ids): Groups two or more elements. ungroup (ids): Removes the group that holds the elements. order (ids, z): Changes the stacking order of elements. layout (optional ids, dir): Arranges elements by the lines between them.

  • name (required, string): Canvas name
  • ops (required, array): Each item is an object whose op field names the op. See the edit ops.

import

Add a Mermaid diagram below the existing content. The importer reads flowchart, sequence and class diagram syntax. Creates the canvas if missing.

  • mermaid (required, string): Mermaid diagram text
  • name (required, string): Canvas name

export

Render a saved canvas and return the text.

  • format (required, string): One of svg, mermaid or clidraw.
  • name (required, string): Canvas name

rename

Rename a canvas.

  • name (required, string): Canvas name
  • to (required, string): New canvas name

delete

Delete a canvas and its undo history.

  • name (required, string): Canvas name

Errors

A failed tool call returns a normal result with isError set to true. Its text is Error: <msg>.

A call to a tool name that does not exist returns a JSON-RPC error with code -32602.
