MCP tools

clidraw mcp serves the commands on the command line page as MCP tools over stdio, for agent clients. It reads one JSON-RPC message per line.

Setup

Add this server to the MCP config of your client:

{
  "mcpServers": {
    "clidraw": {
      "command": "clidraw",
      "args": ["mcp"]
    }
  }
}

A running UI drops its unsaved edits when an agent edits the canvas it has open. Close the canvas in the UI first. See Where files live.

Tools

list

List canvas names as a JSON array.

No parameters.

new

Create an empty canvas.

  • name (required, string): Canvas name

show

Print a canvas as JSON.

  • name (required, string): Canvas name

edit

Edit an existing canvas. Applies all ops or none and returns {"applied":N,"ids":[...]}. Ops: add_shape (x, y, optional kind, w, h, label, color, fill, id), add_text (x, y, text, optional color, id), connect (from, to, optional kind, label, id), set (id, optional label, color, fill, stroke, border, align, bold, link, kind, head), resize (id, w, h), move (id, dx, dy), delete (id), group (ids), ungroup (ids), order (ids, z), layout (optional ids, dir). Shape kind: Rect, Diamond, Cylinder, Parallelogram, Hexagon, Frame. Line kind: Line, Arrow, ArrowStart, ArrowBoth. In set, kind changes a shape kind and head changes a line kind. Colors: red, orange, yellow, green, blue, violet, or none in set. stroke: solid, dashed, dotted. border: single, rounded, double, heavy. align: left, center, right. bold: true or false. link: a URL, or an empty string to clear it. z: front, back, forward, backward. dir: td (default) or lr; layout without ids arranges every shape. A connect end is a shape id or an [x, y] cell.

  • name (required, string): Canvas name
  • ops (required, array): Each item is an object whose op field names the op. See the edit ops.

import

Add a Mermaid diagram below the existing content. The importer reads flowchart syntax only. Creates the canvas if missing.

  • mermaid (required, string): Mermaid diagram text
  • name (required, string): Canvas name

export

Render a saved canvas and return the text.

  • format (required, string): One of svg, mermaid or clidraw.
  • name (required, string): Canvas name

rename

Rename a canvas.

  • name (required, string): Canvas name
  • to (required, string): New canvas name

delete

Delete a canvas and its undo history.

  • name (required, string): Canvas name

Errors

A failed tool call returns a normal result with isError set to true. Its text is Error: <msg>.

A call to a tool name that does not exist returns a JSON-RPC error with code -32602.
