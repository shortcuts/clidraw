Import Mermaid

This guide shows how to turn Mermaid text into shapes. clidraw reads flowchart, sequence, class and state diagrams and rejects other diagram types, such as gantt. clidraw reads nodes, edges and labels, then arranges them with :layout. It rejects state diagrams that use composite states, notes or concurrency. It skips what it cannot draw: note blocks, loops, class cardinality, and the different arrowhead kinds. A flowchart keeps its direction (TD or LR) when you import it and export it again.

Import a file

  1. Open the canvas in clidraw.
  2. Type :import followed by a space and the file path.
  3. Pick the file from the list under the prompt. Up, Down, Ctrl-p and Ctrl-n move the highlight. Tab or Enter fills the path.
  4. Press Enter on a folder to open it.
  5. Press Enter with nothing highlighted to run the import.

The diagram appears on the canvas. If the import fails, clidraw shows each problem with its line number.

Type a Mermaid line

  1. Type :mermaid.
  2. Type one Mermaid line, for example A --> B. clidraw flags mistakes as you type.
  3. Press Tab when a fix is shown. This applies it.
  4. Press Enter to add the diagram.

To turn the fixes off, set quick_fixes to false in the configuration.

Import from the command line

Run clidraw import demo flow.mmd. clidraw adds the diagram below the existing content of demo and creates the canvas if it is missing. Use - as the path to read standard input.

A failed import exits with code 1 and names each problem with its line.
