Getting Started

clidraw is a full-screen whiteboard for the terminal. You draw with the mouse on an infinite canvas.

In this tutorial, you draw two connected shapes, label them and export the drawing as an SVG file. No prior experience is needed.

Before you start

  • Install clidraw first.
  • Use a terminal with true color, mouse reporting and an alternate screen. Most modern terminals have all three.

Draw your first sketch

  1. Start clidraw. Run clidraw first. The terminal clears and shows an empty canvas with a tool bar at the top.
  2. Draw a shape. Click Rect in the tool bar. Drag on the canvas to draw a rectangle. The rectangle appears where you release the mouse.
  3. Draw a second shape. Click Rect again. Drag to the right of the first rectangle.
  4. Label the shapes. Double-click the first rectangle and type Start. Press Enter. Do the same in the second rectangle with End. Each shape shows its text.
  5. Connect them. Click Arrow. Drag from Start to End. Drop the end of the arrow on a shape. The shape turns bold when the end binds to it.
  6. Move a shape. Click the border of End. Drag it somewhere else. The arrow follows.
  7. Export the drawing. Type :export svg and press Enter. Choose what to export, then enter a file path such as first.svg. clidraw writes the file.
  8. Quit. Press Ctrl-c. clidraw saves on its own, so nothing is lost.

Open the drawing again

Run clidraw first. The same canvas opens with your two shapes.
