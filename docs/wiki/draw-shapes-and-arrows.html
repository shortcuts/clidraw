Draw shapes and arrows

This guide shows how to draw shapes, connect them with arrows and label them. It assumes you finished Getting Started.

Start from a template

Press Ctrl-p, choose Edit: Insert template, then choose Flowchart or Sequence diagram. clidraw places the template at the viewport inside one Frame. Press u to undo the insert. A new canvas offers the same templates after you name it; press Esc to leave it blank.

Draw shapes

  1. Pick a shape tool in the top bar: Rect, Diamond, Cylinder, Slant or Hexagon.
  2. Drag on the canvas. The shape appears where you release the mouse.
  3. Repeat for each shape in your diagram.

A click inside a shape selects nothing, so you can draw a new shape on top of another one. Click a border to select a shape. A click within one cell of a border or an arrow selects it too.

Connect shapes

  1. Pick the Arrow tool.
  2. Drag from one shape to another. Drop each end on a shape.
  3. Check that the shape turns bold. The mark ◆ shows where the end attaches.

A bound end follows its shape when the shape moves. To bend a line, select it and drag it. To return to the automatic route, right-click the line and choose Reset route.

Add a connected shape in one click

  1. Select one shape.
  2. Rest the pointer one or two cells outside a side of the shape.
  3. Check that a dim arrow and a dim copy of the shape appear.
  4. Click. clidraw adds the copy and an arrow bound to both shapes. Press u to undo both.

The copy has the same kind and size, and no text. To turn the preview off, set quick_connect = false in the config file.

Label shapes and lines

  1. Double-click a shape or a line.
  2. Type the label.
  3. Press Alt-Enter or Ctrl-j for a new line. Long lines wrap, and the shape grows to fit.
  4. Press Enter to finish.

Double-click empty canvas to place free text.

Arrange shapes

  1. Select the shapes. Use the Select tool (v) and drag a band around them.
  2. Type :layout to arrange them top-down by their connecting lines. Type :layout lr for left to right.

Group shapes

Draw a Frame around shapes, then click its border to move them together. To group without a visible box, select the shapes and press g. Press G to ungroup.

Change a shape kind

  1. Select the shapes.
  2. Press Ctrl-p and choose Change shape.
  3. Press Up or Down to preview each kind.
  4. Press Enter to apply it, or Esc to cancel.

Set the line head

Select a line. The top bar shows its options. Pick a head: none, end, start or both.

Draw other diagrams

clidraw does not limit you to flowcharts. Build any engineering diagram from the same shapes, lines and labels.

To draw a sequence diagram:

  1. Draw a Rect at the top of each participant, and label it with the participant name.
  2. Draw a line down from each Rect with the Arrow tool. Set its head to none.
  3. Draw an Arrow from one line to another for each message, and label it with the message.

To draw an architecture sketch, draw a Rect for each service, label it, and connect the services with labeled Arrows. Draw a Frame around the services that belong together.
