Use with agents

This guide connects clidraw to an AI agent. The agent then reads and edits your canvases through clidraw's MCP tools.

Install clidraw

Install clidraw first. The install page lists every method.

Connect your harness

Run this command. It adds the clidraw MCP server to Claude Code, Codex and Cursor. It also writes the canvas rules into the rules file of Claude Code and Codex. Cursor has no rules file.

clidraw setup --all

To connect one harness, pass its flag:

  • clidraw setup --claude for Claude Code
  • clidraw setup --codex for Codex
  • clidraw setup --cursor for Cursor

A flag needs its harness installed. --claude needs the claude command, and --codex needs the codex command. --all stops at the first harness that is not installed. The harnesses after it are not set up.

To have an agent do the setup, paste this prompt into it:

Install clidraw, run "clidraw setup --all", then read https://clidraw.shrtcts.fr/llms.txt and confirm the list tool works.

Check the connection

Ask the agent to call the list tool. It names your canvases. A JSON array in the reply, even [], means the server works.

Remove clidraw from your harness

Run this command. It removes the MCP server and the canvas rules from each harness. The rest of each rules file stays.

clidraw setup --all --uninstall

Pass one flag to remove one harness, for example clidraw setup --cursor --uninstall.

What the canvas rules tell the agent

The rules tell the agent to name each canvas <repo>-<topic>. They tell it to give each shape an id and to point a shape at its code with set and link. The full text is on the MCP tools page.

Manual setup

Use these steps when clidraw setup cannot run. They add the MCP server only. They do not write the canvas rules.

Claude Code

Run this command once:

claude mcp add clidraw -- clidraw mcp

Codex

Run this command once:

codex mcp add clidraw -- clidraw mcp

Cursor

Add this JSON to .cursor/mcp.json in your project. To add clidraw for every project, put it in ~/.cursor/mcp.json instead:

{
  "mcpServers": {
    "clidraw": {
      "command": "clidraw",
      "args": ["mcp"]
    }
  }
}

Other MCP clients

Add this entry to the mcpServers object of your client config:

{
  "mcpServers": {
    "clidraw": {
      "command": "clidraw",
      "args": ["mcp"]
    }
  }
}

Before an agent edits a canvas

A clidraw window that has the canvas open reloads it within half a second of an agent edit. Unsaved edits in the window are dropped. Where files live explains why.
